Archive

One command. That is the install.

It checks for Docker, starts Archive with everything inside, and keeps your data in one volume. Run it again to update.

$ curl -fsSL https://archive.us.org/install.sh | sh

Then open localhost:8080 and say hello.

Easy to keep.

Nothing to babysit. One folder, one image, your models.

One folder holds it all

Your database, files and settings live in /data, so a backup is one folder.

Upgrades are a pull

Fetch the new image and restart. Archive takes a backup before it changes anything.

Bring your own AI

Point Archive at Ollama, llama.cpp, vLLM or LM Studio. Models never ship inside the image.

Already run Postgres?

Flip one setting and Archive uses yours instead of the bundled one.
